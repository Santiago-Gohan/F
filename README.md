# Encuentro familiarFormulario web para coordinar la celebración de los cumpleaños de los abuelos: disponibilidad, fecha recomendada e ideas de actividades.## Funciones- Registra familias, asistentes, disponibilidad, periodos preferidos e ideas.- Recomienda el mejor día y una ventana de dos días según la disponibilidad; usa los votos de periodo para desempatar.- Permite editar o eliminar respuestas, imprimir y descargar CSV.- Diseño adaptable a móviles y guardado temporal en el navegador.## ImportantePor ahora los datos se guardan en `localStorage` y no se comparten entre familiares ni dispositivos. Cuando elijamos una base de datos, conectaremos el formulario a un servicio compartido. No pongas credenciales privadas en los archivos públicos.Fechas tomadas del código original: abuelo, 8 de diciembre; abuela, 22 de enero. Periodo previsto: diciembre de 2026 a febrero de 2027.
